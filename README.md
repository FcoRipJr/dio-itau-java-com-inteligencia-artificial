# DIO | Itaú - Java com Inteligência Artificial

Repositório de estudos e práticas desenvolvidos durante o
[bootcamp Itaú - Java com Inteligência Artificial](https://www.dio.me/bootcamp/itau-java-com-inteligencia-artificial),
promovido pela [DIO](https://www.dio.me/).

## Organização do repositório

- [`docs/exercicios-java-basico/`](docs/exercicios-java-basico/) reúne os materiais de estudo, exercícios, desafios e projetos usados como referência.
- [`src/`](src/) contém minhas respostas e implementações dos exercícios, desafios e projetos propostos nesses materiais.

Os arquivos de `docs/exercicios-java-basico/` foram importados do repositório
[digitalinnovationone/exercicios-java-basico](https://github.com/digitalinnovationone/exercicios-java-basico),
disponibilizado para apoiar o aprendizado de Java. Os materiais originais são mantidos aqui como referência para acompanhar as soluções em `src/`.

## Objetivo

Praticar os conceitos da linguagem Java apresentados no bootcamp, resolvendo as atividades propostas e organizando o código por tema.

> As implementações em `src/` são respostas desenvolvidas por mim durante os estudos e podem evoluir conforme avanço no bootcamp.
